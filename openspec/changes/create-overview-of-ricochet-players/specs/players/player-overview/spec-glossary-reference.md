# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Visitor | `glossary/business.md` | The actor in every scenario, signed in or not, who reads but never changes players. |
| Player | `glossary/business.md` | The people listed, sorted, filtered, and paginated on the page. |
| Player overview | `glossary/business.md` | The `/players` page this capability specifies. |
| Nationality | `glossary/business.md` | Shown as a flag with a localized country name, and used as a single-select filter. |
| Sex | `glossary/business.md` | Used only as a single-select filter with localized labels. |
| Surname prefix | `glossary/business.md` | Shown before the surname and ignored when sorting. |
| Surname suffix | `glossary/business.md` | Shown after the surname and used as the last sort tie-breaker. |

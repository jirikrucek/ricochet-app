| Term | Definition | Use When | Avoid |
| --- | --- | --- | --- |
| Seed data | Fictional rows loaded by `supabase/seed.sql` into local and CI databases, used by local development, integration tests, and E2E tests. | Describing the database content tests and local development run against. | fixture data, test data, real data |
| Mock data | Fictional in-code fixtures used only by unit tests, never stored in a database. | Describing data a unit test builds or imports instead of querying Supabase. | seed data, stub data |
| Production data | Real rows that exist only in the hosted Preview and Production Supabase projects, loaded by hand with a script kept outside Git. | Describing real players or any other data that must not reach local, CI, or the repo. | seed data, migration data |
| Domain | The racket sport Ricochet as a whole, whose terms are kept in this glossary and apply to every module. | Describing what the whole app is about, or what a module's `domain/` folder represents in code. | business area, subject area |
| Module | A business area of the domain with its own folder under `src/modules/`, such as players or tournaments. | Describing where code lives or which code may import which. | feature, slice, bounded context |
| Feature | One use case of a module, usually reached through a route, whose folder under `features/` orchestrates the module's UI, data access, and domain code. | Describing a use case and the code that orchestrates it. | module, screen, container |
| Shared code | Code in `src/shared/` used by two or more modules, or by a module and `app`. | Describing where code moves when a second module needs it. | global counterpart, common code |
| Domain type | A TypeScript type describing a business concept as the app uses it, usually inferred from a Zod schema and free of storage details. | Contrasting what the app works with against backend rows and UI-only types. | model, entity, DTO |
| Popover | A floating panel anchored to the control that opened it, which neither dims nor blocks the page behind it. | Describing the filters panel at and above 744px. | dropdown, tooltip |
| Sheet | A panel that slides in from a screen edge over a dimmed page and keeps focus inside until it closes (the Shadcn `Sheet`). | Describing the filters panel below 744px and the mobile menu. | drawer, modal (for this component) |
| Internals test | An E2E test in `tests/e2e/internals/` that checks how the app or its test setup is built, such as a shared UI component or a test fixture, and so covers no spec scenario. | Describing an E2E test that is exempt from tracing to a spec scenario. | regression test, harness test, spec-less test |
